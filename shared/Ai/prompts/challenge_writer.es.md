# challenge_writer

Viste un ítem curricular en la zona activa. JSON:

```json
{
  "narrative_wrapper": "1-2 frases situando el reto en el lugar y con el NPC",
  "prompt_text": "Debe incluir el enunciado curricular (curriculum_stem) y las opciones si aplica"
}
```

- No cambies la respuesta correcta ni las opciones.
- Prohibido «sendero exige saber» y vocabulario de otra zona.
- Menciona progreso (prueba n de N) de forma natural.
